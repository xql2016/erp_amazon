# V1产品层面广告自动化
## 产品层面需控制流量
1、运营在EXCEL中列出要加bid的MSKU清单（分站点）,excel格式为第一行为站点id,从第二行开始每列都是写上对应该列站点的SKU清单
2、在广告活动页面，选择对应店铺（广告—广告—全部活动—德/法/意/西）
3、日期选择近3天，MSKU填写运营提供新品的MSKU清单
4、先从广告组的名称判断四种广告组类型，关键词，ASIN，自动，类目，分类处理
### 关键词广告组
将35称为“V1产品层面关键词广告组长期ACOS控制基准上限”
- 广告组最近3天点击=0，不做处理；
- 最近3天点击＞0，点进去看广告组的最近30天数据；
    - 最近30天广告组点击数≥20，花费＞5欧不出单；或者点击数≥20，CPA＞5，分析投放入口的最近30天点击；
        - 投放入口有广告订单，分析ACoS数据；
            - ACoS≤35%，不做处理；
            - ACoS＞35%，将竞价调低为【35%*CPC/ACoS】-0.01,（向上取，保留到小数点两位）
        - 投放入口没有广告订单，分析投放入口点击数；
            - 投放入口点击≥10，关闭该入口。
            - 10＞投放入口点击数≥4
                - 如投放入口竞价＞CPC+0.02-0.01*点击数，将竞价调低为CPC+0.02-0.01*点击数；
                - 如投放入口竞价≤CPC+0.02-0.01*点击数，则竞价不修改；
            - 4＞投放入口点击数＞0
                - 如投放入口竞价＞CPC-0.02，将竞价调低为CPC-0.02；
                - 如投放入口竞价≤CPC-0.02，则竞价不修改；
            - 投放入口点击数=0，不做处理。
    - 最近30天广告组除（点击数≥20，花费＞5欧不出单，和点击数≥20，CPA＞5）这两种以外的情况，分析投放入口的最近30天点击；
        - 投放入口有广告订单，分析ACoS数据；
            - ACoS≤35%，不做处理；
            - ACoS＞35%，将竞价调低为【35%*CPC/ACoS】-0.01,（向上取，保留到小数点两位）
        - 投放入口没有广告订单，分析投放入口点击数；
            - 投放入口点击≥10，关闭该入口。
            - 10＞投放入口点击数≥4
                - 如投放入口竞价＞CPC+0.04-0.01*点击数，将竞价调低为CPC+0.04-0.01*点击数；
                - 如投放入口竞价≤CPC+0.04-0.01*点击数，则竞价不修改；
            - 4＞投放入口点击数＞0
                - 如投放入口竞价＞CPC，将竞价调低为CPC；
                - 如投放入口竞价≤CPC，则竞价不修改；
            - 投放入口点击数=0，不做处理。
