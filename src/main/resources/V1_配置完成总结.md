## 📝 关于Excel文件生成

### Excel文件格式要求

**文件名**:
- 控制流量MSKU清单.xlsx
- 导入流量MSKU清单.xlsx

**格式结构**:
```
第一行: ProfileId1  ProfileId2  ProfileId3  ...
第二行: MSKU-01     MSKU-01     MSKU-01     ...
第三行: MSKU-02     MSKU-02     MSKU-02     ...
...
```

### 生成方式（三选一）

#### 方式1: 使用Java生成器 ⭐ 推荐
已创建 `src/main/java/tools/V1ExcelGenerator.java`

**使用步骤**:
1. 在IDEA中打开 V1ExcelGenerator.java
2. 右键点击 → Run 'V1ExcelGenerator.main()'
3. 自动生成两个Excel文件到resources目录

#### 方式2: 使用Python脚本
已创建 `generate_v1_excel.py` 在项目根目录

**使用步骤**:
```bash
# 1. 安装依赖（如未安装）
pip3 install openpyxl

# 2. 运行脚本
python3 generate_v1_excel.py
```

#### 方式3: 手动创建
1. 新建Excel文件
2. 第一行填入站点ProfileId（数字）
3. 从第二行开始，每列填入对应站点的MSKU
4. 另存为 `.xlsx` 格式

## ⚙️ 如何使用

### 1. 准备Excel文件
使用上述三种方式之一生成或创建Excel文件，并将实际的ProfileId和MSKU填入

### 2. 配置文件路径（可选）
如果Excel文件名或路径不同，需要在配置中指定：

在 `InputConfigurationDetail.txt` 中添加:
```json
{
  "v1SkuControlExcel路径": "src/main/resources/控制流量MSKU清单.xlsx",
  "v1SkuAddExcel路径": "src/main/resources/导入流量MSKU清单.xlsx"
}
```

### 3. 启用V1功能
在 `InputConfigurationDetail.txt` 中添加:
```json
{
  "executeActionCodeList": ["function_v1"]
}
```

### 4. 调整配置参数（可选）
所有配置参数已添加到 `InputConfigurationCustom.txt`，可根据需要调整阈值

## ❗ 重要提示

1. **Excel格式**: 第一行必须是ProfileId（数字），第二行开始才是MSKU
2. **文件位置**: Excel文件必须放在resources目录或配置中指定的路径
3. **数据替换**: 示例Excel中的ProfileId和MSKU都是示例数据，需要替换为实际值
4. **配置优先级**: InputConfigurationCustom.txt 中的配置会覆盖默认值
5. **生成工具**: Java生成器需要在IDEA中运行，Python脚本需要安装openpyxl
