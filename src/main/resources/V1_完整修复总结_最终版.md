## 🚨 第二轮发现的重大问题

### 🔴 问题5：自动/类目广告组策略实现完全错误（非常严重）

#### 问题描述
自动广告组和类目广告组的控制流量策略与关键词/ASIN完全不同，但第一轮修复时错误地让所有类型使用了相同逻辑！

#### 关键差异对比表

| 场景 | 关键词/ASIN | 自动/类目 |
|------|------------|----------|
| **关闭投放入口** | 点击≥10 | 点击≥20（设Bid=0.02） |
| **高点击无转化 - 10-20点击** | N/A（不存在） | CPC+0.07-0.01×点击 |
| **高点击无转化 - 4-10点击** | CPC+0.02-0.01×点击 | N/A（不存在） |
| **高点击无转化 - 1-10点击** | 分段：4-10和1-4 | 统一CPC-0.02 |
| **非高点击 - 10-20点击** | N/A（不存在） | CPC+0.08-0.01×点击 |
| **非高点击 - 4-10点击** | CPC+0.04-0.01×点击 | CPC-0.01 |
| **非高点击 - 0-4点击** | CPC | 不处理 |

#### 具体差异说明

##### 1. 点击≥20的处理
- **关键词/ASIN**：不会到达这个分支（点击≥10就关闭了）
- **自动/类目**：将Bid改为0.02（强制降至最低，而不是关闭）

##### 2. 10-20点击区间
- **关键词/ASIN**：不存在此区间
- **自动/类目**：
  - 高点击无转化：CPC + 0.07 - 0.01 × 点击数
  - 非高点击无转化：CPC + 0.08 - 0.01 × 点击数

##### 3. 0-10点击区间（高点击无转化）
- **关键词/ASIN**：
  - 4-10点击：CPC + 0.02 - 0.01 × 点击数
  - 1-4点击：CPC - 0.02
- **自动/类目**：
  - 0-10点击（>0）：统一CPC - 0.02

##### 4. 4-10点击区间（非高点击无转化）
- **关键词/ASIN**：CPC + 0.04 - 0.01 × 点击数
- **自动/类目**：CPC - 0.01

##### 5. 0-4点击区间（非高点击无转化）
- **关键词/ASIN**：CPC
- **自动/类目**：不处理

## 修复后的代码逻辑（自动/类目广告组）

### 有订单投放入口
```java
// 逻辑与关键词/ASIN相同
if (ACOS > 35%) {
    目标Bid = (35% × CPC / ACOS) - 0.01 (向上取整)
}
```

### 无订单投放入口
```java
if (点击 >= 20) {
    // 【特殊】将Bid改为0.02（强制降至最低）
    subtractBid(0.02)
    
} else if (点击 >= 10) {
    // 【特殊】10-20点击区间
    if (高点击无转化) {
        目标Bid = CPC + 0.07 - 0.01 × 点击数
    } else {
        目标Bid = CPC + 0.08 - 0.01 × 点击数
    }
    
} else if (高点击无转化 && 点击 > 0) {
    // 【特殊】高点击无转化，0<点击<10统一处理
    目标Bid = CPC - 0.02
    
} else if (!高点击无转化 && 点击 >= 4) {
    // 【特殊】非高点击无转化，4≤点击<10
    目标Bid = CPC - 0.01
}
// 非高点击无转化，0<点击<4：不处理
```
