# V1 Function 策略分支详细说明文档

## 文档概述

本文档详细描述了V1产品层面广告自动化功能的完整策略分支判断逻辑，包括**控制流量**（降Bid）和**导入流量**（加Bid）两大功能模块。

**功能代码**: `function_v1`  
**入口类**: `ProductLevelActionV1`  
**数据源**: Excel文件（按站点和MSKU维度）

---

## 一、整体架构流程

```
V1 产品层面广告自动化
    │
    ├─── 1. 读取Excel文件（按站点ProfileId分组MSKU列表）
    │
    ├─── 2. 控制流量处理（ControlTrafficActionV1）
    │    └─── 降低表现不佳的广告组/投放入口竞价
    │
    └─── 3. 导入流量处理（ImportTrafficActionV1）
         └─── 提高表现良好的广告组/投放入口竞价
```

---

## 二、控制流量策略（降Bid控制垃圾流量）

### 数据源配置
- **Excel文件路径**: `FilePath.v1SkuControlExcel`
- **数据查询范围**: 
  - 广告组数据：近30天
  - 活跃度判断：近3天
  - 投放入口数据：近30天

### 完整处理流程

```
Step 1: 按站点读取MSKU列表
   ↓
Step 2: 查询该MSKU的所有广告组（近30天数据）
   ↓
Step 3: 广告组前置条件筛选
   ├─ 广告组名称为空 → 跳过
   ├─ 广告组状态 ≠ enabled → 跳过
   ├─ 无法识别广告组类型 → 跳过
   └─ 近3天点击 = 0 → 跳过（不活跃）
   ↓
Step 4: 广告组层面条件判断（标记高点击无转化）
   ├─ 如果 (点击≥20 且 花费>5欧 且 无订单) → 标记为"高点击无转化"
   ├─ 如果 (点击≥20 且 CPA>5) → 标记为"高点击无转化"
   └─ 继续处理投放入口（根据标记使用不同公式）
   ↓
Step 5: 查询投放入口列表（近30天数据）
   ↓
Step 6: 按投放入口订单情况分类处理
   ├─ 有订单 → 按ACOS降Bid
   └─ 无订单 → 按点击数降Bid或关闭
```

### 投放入口处理规则

#### 情况A：投放入口有订单（orders > 0）

| ACOS范围 | 处理动作 | 目标Bid计算公式 |
|---------|---------|----------------|
| ACOS > 35% | 降低竞价 | `(35% × CPC / ACOS) - 0.01` |
| ACOS ≤ 35% | 不处理 | - |

**说明**: 向上取整，保留2位小数

#### 情况B：投放入口无订单（orders = 0）

**⚠️ 重要：自动/类目广告组与关键词/ASIN有不同的规则，见下方说明**

##### 关键词/ASIN广告组

| 点击数范围 | 高点击无转化 | 非高点击无转化 | 前置条件 |
|-----------|-------------|--------------|---------|
| 点击 ≥ 10 | **关闭投放入口** | **关闭投放入口** | - |
| 4 ≤ 点击 < 10 | `CPC + 0.02 - 0.01 × 点击数` | `CPC + 0.04 - 0.01 × 点击数` | 当前Bid > 目标Bid |
| 0 < 点击 < 4 | `CPC - 0.02` | `CPC` | 当前Bid > 目标Bid |
| 点击 = 0 | 不处理 | 不处理 | - |

##### 自动/类目广告组

| 点击数范围 | 高点击无转化 | 非高点击无转化 | 前置条件 |
|-----------|-------------|--------------|---------|
| 点击 ≥ 20 | **设Bid=0.02** | **设Bid=0.02** | - |
| 10 ≤ 点击 < 20 | `CPC + 0.07 - 0.01 × 点击数` | `CPC + 0.08 - 0.01 × 点击数` | 当前Bid > 目标Bid |
| 4 ≤ 点击 < 10（仅非高点击） | - | `CPC - 0.01` | 当前Bid > 目标Bid |
| 0 < 点击 < 10（仅高点击） | `CPC - 0.02` | - | 当前Bid > 目标Bid |
| 0 < 点击 < 4（仅非高点击） | - | 不处理 | - |
| 点击 = 0 | 不处理 | 不处理 | - |

### 关键配置参数

| 配置项 | 默认值 | 说明 |
|-------|-------|------|
| V1产品层面关键词广告组长期ACOS控制基准上限 | 35 | ACOS判断基准 |
| V1控制流量花费阈值（欧元） | 5 | 高花费无转化判断 |
| V1控制流量CPA阈值 | 5 | 高CPA判断 |
| V1控制流量点击数阈值 | 20 | 高点击量判断 |

## 三、导入流量策略（加Bid增加有效流量）

### 数据源配置
- **Excel文件路径**: `FilePath.v1SkuAddExcel`
- **数据查询范围**:
  - 广告组数据：近30天
  - 昨天数据：昨天（1,1）
  - 投放入口数据：近30天

### 完整处理流程

```
Step 1: 按站点读取MSKU列表
   ↓
Step 2: 查询该MSKU的所有广告组（近30天数据）
   ↓
Step 3: 广告组前置条件筛选
   ├─ 广告组名称为空 → 跳过
   ├─ 广告组状态 ≠ enabled → 跳过
   └─ 无法识别广告组类型 → 跳过
   ↓
Step 4: 查询广告组昨天的数据
   ↓
Step 5: 根据点击数和订单情况分三种情况处理
   ├─ 情况A: 近30天点击 ≥ 15
   ├─ 情况B: 近30天点击 < 15 且 昨天点击 ≥ 1
   └─ 情况C: 近30天点击 < 15 且 昨天点击 < 1
```

### 广告组层面判断（三种情况）

**⚠️ 重要：自动/类目广告组的点击阈值是10，关键词/ASIN是15**

#### 关键词/ASIN广告组

##### 情况A：近30天点击 ≥ 15

| 广告组订单情况 | 处理动作 |
|--------------|---------|
| 无订单 | 不处理 |
| 有订单 | 处理有订单的投放入口（按ACOS区间） |

##### 情况B：近30天点击 < 15 且 昨天点击 ≥ 1

| 广告组订单情况 | 处理动作 |
|--------------|---------|
| 无订单 | 不处理 |
| 有订单 | 处理有订单的投放入口（按ACOS区间） |

##### 情况C：近30天点击 < 15 且 昨天点击 < 1

→ **按投放入口的点击和订单数据详细分析**

#### 自动/类目广告组

##### 情况A：近30天点击 ≥ 10

| 广告组订单情况 | 处理动作 |
|--------------|---------|
| 无订单 | 不处理 |
| 有订单 | 处理有订单的投放入口（按ACOS区间） |

##### 情况B：近30天点击 < 10 且 昨天点击 ≥ 1

| 广告组订单情况 | 处理动作 |
|--------------|---------|
| 无订单 | 不处理 |
| 有订单 | 处理有订单的投放入口（按ACOS区间） |

##### 情况C：近30天点击 < 10 且 昨天点击 < 1

→ **按投放入口的曝光和订单数据详细分析**（与关键词/ASIN不同）

### 投放入口处理规则

#### 规则1：处理有订单的投放入口（orders ≥ 1）

**前置条件**: 近1天内没有变更日志（防止重复操作）

| ACOS区间 | 处理动作 | 目标Bid公式 | 说明 |
|---------|---------|-----------|------|
| 35% < ACOS ≤ 60% | 1. 打开投放入口<br>2. 提高竞价 | `(35% × CPC / ACOS) - 0.01` | 保持入口打开 |
| 25% < ACOS ≤ 35% | 1. 打开投放入口<br>2. 提高竞价 | `CPC - 0.01` | 竞价不低于CPC-0.01 |
| 15% < ACOS ≤ 25% | 1. 打开投放入口<br>2. 提高竞价 | `CPC` | 竞价不低于CPC |
| ACOS ≤ 15% | 1. 打开投放入口<br>2. 提高竞价 | `CPC + 0.02` | 竞价不低于CPC+0.02 |
| ACOS > 60% | 不处理 | - | 超出可接受范围 |

**说明**: 第一个公式向上取整，保留2位小数

#### 规则2：处理无订单的投放入口（情况C专用）

##### 关键词/ASIN广告组

**适用场景**: 近30天点击<15 且 昨天点击<1

| 投放入口点击 | 投放入口订单 | 处理动作 |
|------------|------------|---------|
| 点击 ≥ 1 | orders = 0 | 不处理 |
| 点击 = 0 | orders = 0 | 按当前Bid分级提高 ↓ |
| - | orders ≥ 1 | 按ACOS区间处理（见规则1） |

**点击=0且无订单时，按Bid分级提高：**

**前置条件**: 近1天内没有变更日志

| 当前Bid范围 | 处理动作 | 目标Bid计算 |
|-----------|---------|-----------|
| Bid ≤ 0.3 | 提高竞价 | `当前Bid + 0.02` |
| 0.3 < Bid ≤ 0.45 | 提高竞价 | `当前Bid + 0.01` |
| Bid > 0.45 | 不处理 | - |

##### 自动/类目广告组

**适用场景**: 近30天点击<10 且 昨天点击<1

| 投放入口情况 | 昨天曝光 | 处理动作 |
|------------|---------|---------|
| orders = 0，点击 ≥ 1 | - | 不处理 |
| orders = 0，点击 = 0 | ≥ 20 | 不处理 |
| orders = 0，点击 = 0 | < 20 | 按当前Bid分级提高 ↓ |
| orders ≥ 1 | - | 按ACOS区间处理（见规则1） |

**点击=0且无订单且昨天曝光<20时，按Bid分级提高：**

**前置条件**: 近1天内没有变更日志

| 当前Bid范围 | 处理动作 | 目标Bid计算 |
|-----------|---------|-----------|
| Bid ≤ 0.3 | 提高竞价 | `当前Bid + 0.02` |
| 0.3 < Bid ≤ 0.4 | 提高竞价 | `当前Bid + 0.01` |
| Bid > 0.4 | 不处理 | - |

### 关键配置参数

| 配置项 | 关键词/ASIN | 自动/类目 | 说明 |
|-------|-----------|-----------|------|
| 投放入口保持打开的ACOS临界值 | 60 | 60 | 最高可接受ACOS |
| 投放入口ACOS控制基准 | 35 | 35 | ACOS基准线 |
| 投放入口竞价不低于CPC-0.01的ACOS临界值 | 25 | 25 | 中等ACOS |
| 投放入口竞价不低于CPC+0.02的ACOS临界值 | 15 | 15 | 优秀ACOS |
| 导入流量点击数阈值 | 15 | 10 | 有效数据量判断 |
| 导入流量Bid调整阈值1 | 0.3 | 0.3 | 低Bid阈值 |
| 导入流量Bid调整阈值2 | 0.45 | 0.4 | 中Bid阈值 |
| 导入流量昨天曝光阈值 | - | 20 | 自动/类目专用 |

## 五、广告组类型说明

V1功能支持以下四种广告组类型，每种类型有对应的处理类：

| 广告组类型 | 枚举值 | 控制流量处理类 | 导入流量处理类 |
|-----------|-------|--------------|--------------|
| 关键词广告组 | KEY_AD_GROUP | KeyAdGroupDetailActionV1 | KeyAdGroupDetailActionV1 |
| ASIN广告组 | ASIN_AD_GROUP | AsinAdGroupDetailActionV1 | AsinAdGroupDetailActionV1 |
| 自动广告组 | AUTO_AD_GROUP | AutoAdGroupDetailActionV1 | AutoAdGroupDetailActionV1 |
| 类目广告组 | CATEGORY_AD_GROUP | CategoryAdGroupDetailActionV1 | CategoryAdGroupDetailActionV1 |

**重要说明**: 
- **关键词和ASIN广告组**使用相同的处理逻辑
- **自动和类目广告组**使用相同的处理逻辑，但与关键词/ASIN有重要差异：
  - **控制流量**：点击≥20设Bid=0.02（不关闭），10-20点击区间特殊处理
  - **导入流量**：点击阈值为10（不是15），使用曝光判断（不是点击）
- 通过配置文件可以为每种类型设置独立的阈值

## 七、所有计算公式汇总

### 控制流量公式

#### 关键词/ASIN广告组

| 场景 | 高点击无转化 | 非高点击无转化 | 说明 |
|-----|------------|--------------|------|
| 有订单降Bid | `(35% × CPC / ACOS) - 0.01` | 同左 | 向上取整2位小数 |
| 无订单点击≥10 | 关闭投放入口 | 关闭投放入口 | - |
| 无订单4-9点击 | `CPC + 0.02 - 0.01 × 点击数` | `CPC + 0.04 - 0.01 × 点击数` | - |
| 无订单1-3点击 | `CPC - 0.02` | `CPC` | - |

#### 自动/类目广告组

| 场景 | 高点击无转化 | 非高点击无转化 | 说明 |
|-----|------------|--------------|------|
| 有订单降Bid | `(35% × CPC / ACOS) - 0.01` | 同左 | 向上取整2位小数 |
| 无订单点击≥20 | 设Bid=0.02 | 设Bid=0.02 | 不关闭 |
| 无订单10-19点击 | `CPC + 0.07 - 0.01 × 点击数` | `CPC + 0.08 - 0.01 × 点击数` | - |
| 无订单0-9点击（>0） | `CPC - 0.02` | - | 统一处理 |
| 无订单4-9点击 | - | `CPC - 0.01` | 仅非高点击 |
| 无订单0-3点击（>0） | - | 不处理 | 仅非高点击 |

### 导入流量公式

| ACOS区间 | 公式 | 说明 |
|---------|------|------|
| ACOS≤15% | `CPC + 0.02` | 优秀表现 |
| 15%<ACOS≤25% | `CPC` | 良好表现 |
| 25%<ACOS≤35% | `CPC - 0.01` | 一般表现 |
| 35%<ACOS≤60% | `(35% × CPC / ACOS) - 0.01` | 需控制的表现，向上取整2位小数 |

### 无订单低Bid提升公式

#### 关键词/ASIN广告组

| 当前Bid范围 | 公式 |

## 九、处理结果统计

### 统计维度

- **已处理MSKU数量**: 至少有一个广告组被处理的MSKU数量
- **未处理MSKU列表**: 所有广告组都未被处理的MSKU（会输出提示）

### 未处理原因

1. **查询不到广告组**: Excel中的MSKU在系统中没有对应的广告组
2. **所有广告组都被过滤**: 
   - 广告组未启用
   - 近期无点击（不活跃）
   - 满足排除条件（高点击无转化等）
3. **投放入口数据不满足条件**:
   - ACOS在不需处理的区间
   - 点击数在不需处理的范围
   - 近期已有操作日志

## 十、注意事项

### 1. Excel文件格式要求

- **第一行**: 站点ProfileId（数字）
- **第二行开始**: 每列对应站点的MSKU清单
- **文件位置**: 
  - 控制流量: `FilePath.v1SkuControlExcel`
  - 导入流量: `FilePath.v1SkuAddExcel`

### 2. 操作安全机制

- **日志防重复**: 导入流量功能会检查近1天操作日志，避免短期内重复调整
- **前置条件严格**: 多层筛选条件确保只处理符合条件的广告组
- **分级处理**: 根据数据表现分级操作，避免过度调整

### 3. 配置灵活性

- 所有阈值都可通过配置文件调整
- 不同广告组类型可以配置独立的参数
- 支持按站点和Hub维度过滤处理范围

### 4. 与其他功能的关系

- V1是产品层面（MSKU维度）的自动化
- 先执行控制流量，再执行导入流量
- 可与其他功能（V2、V3等）组合使用
