# Excel文件格式要求：
# - 第一行：站点ProfileId（数字）
# - 第二行开始：每列对应站点的MSKU清单
# - 示例：
#   12345678    23456789    34567890
#   ABC-001     DEF-001     GHI-001
#   ABC-002     DEF-002     GHI-002
#   ABC-003     DEF-003     GHI-003

# ACOS区间说明（导入流量）：
# - ACOS ≤ 15%：优秀表现，目标Bid = CPC + 0.02
# - 15% < ACOS ≤ 25%：良好表现，目标Bid = CPC
# - 25% < ACOS ≤ 35%：一般表现，目标Bid = CPC - 0.01
# - 35% < ACOS ≤ 60%：需控制表现，目标Bid = (35% × CPC / ACOS) - 0.01
# - ACOS > 60%：不处理

# 控制流量处理逻辑：
# - 排除：点击≥20 且 (花费>5欧无订单 或 CPA≥5)
# - 有订单投放入口：ACOS>35% 时降Bid
# - 无订单投放入口：
#   * 点击≥10：关闭投放入口
#   * 4≤点击<10：降Bid至 CPC+0.04-0.01×点击数
#   * 0<点击<4：降Bid至 CPC
#   * 点击=0：不处理

# 导入流量处理逻辑：
# - 点击≥15（或昨天≥1）且有订单：按ACOS区间处理投放入口
# - 点击<15且昨天<1：
#   * 投放入口有订单：按ACOS区间处理
#   * 投放入口无订单且点击=0：
#     - Bid≤0.3：增加0.02
#     - 0.3<Bid≤0.45：增加0.01
#     - Bid>0.45：不处理

# 注意事项：
# 1. 所有金额默认为欧元
# 2. ACOS值为百分比，配置时使用整数（如35表示35%）
# 3. 导入流量功能会检查近1天操作日志，避免重复操作
# 4. 建议根据实际业务数据定期优化阈值
# 5. 不同广告组类型可配置不同参数实现差异化管理
